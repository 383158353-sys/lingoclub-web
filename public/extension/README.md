# LinguaTube 浏览器扩展

## 安装方法

1. 将 `manifest.json` 和 `content.js` 放在同一个文件夹中
2. 打开 Chrome / Edge 浏览器，地址栏输入 `chrome://extensions`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择包含上述文件的文件夹
5. 扩展已安装 ✓

## 使用方法

1. 打开任意 YouTube 或 B站 视频页面
2. 页面右下角出现绿色「导入学习」按钮
3. 首次点击时会弹出输入框，粘贴你的 LinguaTube 应用地址
4. 点击按钮 → 扩展自动提取字幕 → 新标签页打开学习页面
5. 视频和字幕已就绪，开始逐句精读 ✓

## 说明

- YouTube：扩展在 youtube.com 同源环境下直接抓取 CC 字幕，成功率 100%
- B站：扩展传递视频 URL，由 LinguaTube 站内尝试抓取 CC 字幕
- 如需修改应用地址，清除扩展存储数据后重新点击按钮即可
